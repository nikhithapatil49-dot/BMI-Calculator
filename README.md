# BMI Calculator

## Live Link
https://nikhithapatil49-dot.github.io/bmi-calculator/

## What it does?
Enter height and weight -> shows BMI and category

## Formula
BMI = weight(kg) / (height(m) * height(m))

## Categories
<18.5 Underweight
18.5-24.9 Normal
25-29.9 Overweight
30+ Obesity
